# HECATE — decision register

This register records deviations, exceptions and choices against `DESIGN-STANDARD.md` v1.4.0.

- **Order:** newest first.
- **Format:** the standard's Appendix C. A SHOULD deviation is one line (G-06). A MUST exception is a full record that the repository owner approves (G-07).
- **Not in force:** an entry marked `PENDING`. Until it is approved, the code it describes is non-conformant.
- **Who drafts:** agents draft records and never approve them.
